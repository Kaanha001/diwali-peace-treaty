# 🪔 Interactive Diwali Peace Treaty & Greeting Web App

A mobile-first, interactive festive web experience built with HTML5, Tailwind CSS, and Vanilla JavaScript Canvas animations.

### ✨ Features
- **Interactive SVG Diyas:** Tap-to-light animations with custom notes.
- **Wax-Sealed Letters:** Smooth CSS grid unfold animations.
- **HTML5 Canvas Scratch Card:** Touch-enabled golden foil coupon.
- **Floating Sky Lanterns:** Particle animation with custom wish release.
- **Smart Audio Integration:** Custom background music controller with auto-pause on video playback.
